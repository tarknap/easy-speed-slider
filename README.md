# Easy Speed Slider (ESS) — плагин OrcaSlicer

Вкладка в главном окне называется **ESS**, полное название **Easy Speed Slider** — сверху на
самой странице и в окне Plugins. У ярлыка вкладки — иконка спидометра из ресурсов OrcaSlicer.

Короткий ползунок задаёт **скорость внешней стенки**. Остальные параметры задаются
**множителем к этой скорости** либо **абсолютной скоростью в мм/с** — у каждой строки свой
режим и своё пояснение «почему так». Интерфейс двуязычный: **RU / EN**.

Плагин также сверяет скорость внешней стенки с **диапазоном избегания резонанса**
(Resonance avoidance, в русском UI — «Избегание ряби» в группе «Борьба с вертикальными
артефактами») из настроек принтера и предупреждает, если выставленная скорость попадёт в
диапазон избегаемых скоростей.

```
скорость внешней стенки = ползунок, мм/с
строка в режиме «×»    : значение_i = ползунок × ratio_i     (множитель к стенке)
строка в режиме «мм/с» : значение_i = заданная скорость      (не зависит от ползунка)
```

По умолчанию у каждой строки режим «×», а `ratio_i` снят с пресета:
`ratio_i = база_i / база внешней стенки`. Поэтому если ползунок стоит на текущей скорости
стенки и строки не тронуты, применение ничего не меняет — это исходная пропорция профиля.

## Требования

- OrcaSlicer **2.5.0-beta / 2.5.0-rc или nightly**. В 2.5.0-alpha и в 2.4.x API
  `orca.host.preset` ещё нет — плагин честно скажет об этом в статусе.
- API редактирования пресетов (`begin_update` / `set` / `commit`) в вики пока не описан,
  он найден в исходниках `src/slic3r/plugin/host/PluginHostPresets.cpp`. Это значит:
  работает, но может измениться в следующих сборках.

## Установка

1. Скопировать папку `orca-speedslider` в каталог плагинов OrcaSlicer:

   | ОС | Куда |
   |---|---|
   | Windows | `%APPDATA%\OrcaSlicer\orca_plugins\` |
   | macOS | `~/Library/Application Support/OrcaSlicer/orca_plugins/` |
   | Linux | `~/.config/OrcaSlicer/orca_plugins/` |

   Внутри папки должен лежать ровно один `.py`-файл (`speed_slider.py`); `README.md` не мешает.

   Либо: **Plugins → Install local plugin** и выбрать `speed_slider.py` (файл должен лежать
   **вне** `orca_plugins`, иначе установщик упрётся в коллизию имён).

2. Открыть **Plugins** (главное меню), включить `Easy Speed Slider`.
3. При загрузке OrcaSlicer спросит разрешение на создание потока — нужен «Yes».

## Как пользоваться

1. Выбрать process-пресет.
2. Открыть вкладку **ESS** в главном окне.
3. Ползунок **«Внешняя стенка»** (короткий) задаёт скорость стенки; рядом числовое поле.
4. В таблице у каждой строки:

   | Параметр | Значение | Станет | Почему так |
   |---|---|---|---|
   | Внутренняя стенка | `2` `×` | 90 | стенка 45, инфилл ×2 даёт 90 |
   | Мосты | `25` `мм/с` | 25 | мосты всегда 25 |

   - переключатель `×` / `mm/s` задаёт, чем вы управляете;
   - `×` — множитель к скорости внешней стенки (`2` = «вдвое быстрее стенки»);
   - `мм/с` — абсолютная скорость, которая **не** едет за ползунком;
   - «Станет» пересчитывается сразу; изменённые строки подсвечены, сверху
     «отклонений: 2 из 8»;
   - если в настройках принтера заполнен диапазон избегаемых скоростей, под ползунком
     виден этот диапазон, а попадание в него подсвечивается предупреждением
     (см. «Избегание резонанса (VFA)»).

5. Пояснения сохраняются сами через 0.6 с после последнего символа.
6. **Применить** — стенка и все строки уходят в пресет одним атомарным коммитом.
7. Пресет становится «изменённым» (звёздочка) — сохранить его в OrcaSlicer. Скорости на диск
   плагин не пишет, сохраняются только пояснения и режимы строк.

Кнопки:

- **Сбросить к базе** — вернуть каждую строку в режим `×` с исходной пропорцией пресета
  (ещё не применено).
- **Переснять базу** — заново снять значения с текущего состояния пресета.

Внизу страницы — короткая справка («Как это работает») тем же языком, что выбран в интерфейсе.

### Язык

Переключатель **RU / EN** справа сверху. Переводится весь интерфейс, включая справку снизу;
выбор запоминается в файле настроек плагина и применяется при следующем открытии.

### Переключение режима строки

При переключении `×` → `мм/с` в поле подставляется текущее вычисленное значение (ползунок ×
множитель), дальше оно фиксируется. При обратном переключении `мм/с` → `×` множитель
пересчитывается как `скорость / текущая скорость стенки`.

## Где хранятся пояснения, режимы и язык

`data_dir()/orca_plugins/plugin_data/<plugin_key>/speed_slider.json` — приватная папка плагина
(`orca.host.plugin.storage()`), доступна на запись без запросов аудита. Формат:

```json
{
  "version": 5,
  "ui": { "lang": "ru" },
  "presets": {
    "0.20mm Standard @BBL X1C": {
      "slider": 45.0,
      "anchor": 60.0,
      "rows": {
        "inner_wall_speed": { "mode": "ratio", "ratio": 2.0, "speed": 150.0, "note": "инфилл ×2" },
        "bridge_speed":     { "mode": "speed", "ratio": 0.5, "speed": 25.0,  "note": "мосты всегда 25" }
      },
      "updated": "05.11 14:12"
    }
  }
}
```

Ключ — отображаемое имя process-пресета. Если файл хранилища недоступен, поля пояснений
отключаются с подсказкой, остальное работает.

## Какие скорости в таблице

`inner_wall_speed`, `sparse_infill_speed`, `internal_solid_infill_speed`, `top_surface_speed`,
`gap_infill_speed`, `support_speed`, `support_interface_speed`, `bridge_speed` —
плюс внешняя стенка (`outer_wall_speed`), которой управляет ползунок.

Сознательно **не** трогаются:

- `travel_speed`, `initial_layer_speed`, `initial_layer_infill_speed` — это не скорости печати
  в смысле качества поверхности;
- `small_perimeter_speed`, `overhang_1_4…4_4_speed` — они уже в процентах от `outer_wall_speed`
  (`ratio_over` в `PrintConfig.cpp`) и едут за ним сами;
- скорости в filament-пресете (`filament_max_volumetric_speed`, `filament_ironing_speed`).

Список задаётся константой `ROWS` в начале `speed_slider.py` — добавить/убрать строку можно
без правки остального кода; подписи задаются там же в двух языках.

## Избегание резонанса (VFA)

Плагин читает из активного printer-пресета три опции OrcaSlicer:

- `resonance_avoidance` (в UI — «Избегание ряби» в группе «Борьба с вертикальными артефактами»);
- `min_resonance_avoidance_speed`, `max_resonance_avoidance_speed` — диапазон избегаемых скоростей.

Диапазон переснимается при открытии вкладки, смене process-пресета и смене принтера.

Если диапазон заполнен (`min > 0` и `max > min`), плагин сверяет с ним скорость внешней
стенки: попадание внутрь подсвечивает ползунок и числовое поле и показывает предупреждение.

- Если «Избегание ряби» **включено**, OrcaSlicer в G-code правит внешние периметры так:
  нижняя половина диапазона прижимается к минимуму, верхняя — поднимается к максимуму;
  ровно `min`, `max` и скорости выше `max` не меняются. В предупреждении видно, на какой
  скорости стенка реально напечатается, и подсказка «безопасно: < min или ≥ max».
- Если «Избегание ряби» **выключено**, плагин всё равно предупреждает, что скорость попала
  в нежелательный для принтера диапазон, и добавляет, что слайсер её не скорректирует.

Плагин ничего не меняет сам: если такая скорость нужна, выставьте её вне диапазона или
включите/отключите избегание резонанса в настройках принтера. Коррекция в G-code применяется
только к внешним периметрам — остальные строки таблицы слайсер не трогает. Предупреждение
считается по настроенной скорости; фактическая может оказаться ниже из-за
`filament_max_volumetric_speed`. При мультиэкструдере предупреждение считается по значению
на ползунке (первый экструдер), остальные значения стенки масштабируются пропорционально.

## Объёмный расход филамента

Плагин оценивает предел скорости по лимиту филамента `filament_max_volumetric_speed`:

```
v_max = лимит / (ширина_линии × высота_слоя × flow-ratio)
```

- Берётся самый жёсткий лимит среди филаментов (`filament_max_volumetric_speed` — массив;
  в расчёт идёт минимум, потому что AMS может печатать любым из них).
- Ширины линий по ролям и проценты резолвятся по диаметру сопла; `0` («авто») — по
  `line_width`, затем по соплу.
- Учитываются `print_flow_ratio`, `filament_flow_ratio`, а ролевые коэффициенты — только
  если в профиле включён `set_other_flow_ratios`.

Под таблицей показывается лимит и список конфликтов, например «Внутренняя стенка 270 > 120 мм/с».
Строки, где слайсер срежет скорость, подсвечиваются в колонке «Станет», ползунок — при конфликте
внешней стенки. Плагин ничего не меняет и безопасные значения не подставляет.

Это **оценка**: адаптивная высота слоя, Arachne/переменная ширина, `filament_adaptive_volumetric_speed`
и другие ограничения не моделируются. Пересчитывается при открытии вкладки, смене process-пресета,
принтера и филамента.

## Ограничения

- Правки применяются к **текущему активному** process-пресету. Системный пресет OrcaSlicer
  попросит сохранить как пользовательский — это обычный флоу.
- Плагин **не меняет** скорость сам, когда она попадает в полосу избегания резонанса: он
  только предупреждает (см. «Избегание резонанса (VFA)»). Решение — поменять скорость или
  отключить избегание в настройках принтера.
- Оценка по `filament_max_volumetric_speed` приблизительная: не учитывает адаптивную высоту
  слоя, Arachne/переменную ширину и `filament_adaptive_volumetric_speed`. Фактический потолок
  скорости может быть ниже.
- Мультиэкструдер: ползунок масштабирует все значения стенки пропорционально; строки в режиме
  «×» считаются от соответствующего экструдеру значения стенки.
- Строки со значением `0` («авто») в таблицу не попадают.
